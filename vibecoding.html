말로 설계하고,
코드로 이해한다.

원하는 결과를 말로 주문하면 코드가 생성되고 그래픽으로 바로 실행됩니다. 이후 코치가 코드를 한 줄씩 해설하고, 실행 과정을 추적하며, 직접 수정하는 과제로 이어집니다. 같은 프로그램을 파이썬·자바·C로 비교하며 언어별 설계 철학을 익힙니다.

파이썬같은 동작, 다른 문법1줄

        

      

    

  


  

    

      
세 언어의 설계 철학

      
어떤 언어로 시작해도 됩니다. 상단에서 언제든 언어를 전환할 수 있고, 각 프로젝트 마지막 단계에서 세 언어의 코드를 나란히 비교합니다.

      

    

  


  

    

      
커리큘럼

      
기초 문법 6단계로 출력 → 변수 → 조건 → 반복 → 리스트를 다지고, 비주얼 프로젝트에서 실제 현업 라이브러리로 그래픽·데이터 시각화·애니메이션을 만듭니다.

      
언어별 대표 프로젝트
각 언어가 실제로 가장 많이 쓰이는 분야의 결과물을 만듭니다. 자바는 웹 서버, 파이썬은 AI, C는 임베디드 제어.
    
      
    비주얼 프로젝트
    바이브코딩으로 결과물을 먼저 눈으로 확인하고, 그 코드를 해부합니다.
      
      
      기초 문법
      모든 프로그램의 뼈대가 되는 다섯 가지 개념.
        
    
        
  
        

  
        
    
        
      
        
        
        프로젝트 하나는 7단계로 진행됩니다
        
        
        외국어를 배울 때처럼, 단어를 쪼개 읽고 문장 구조를 이해한 뒤 직접 써 보는 순서입니다.
        
        
          
          
        1. 개요무엇을 만들지, 어떤 개념과 라이브러리를 쓰는지 확인합니다.
          2. 
          
        2. 바이브 코딩원하는 결과를 말로 주문하면 코드가 생성되고 바로 실행됩니다.
          3. 
          
        3. 코드 해설각 줄을 토큰 단위로 분해하고, 읽는 법과 의미를 짚습니다.
          4. 
          
        4. 개념 체크코드 속에서 정답 토큰을 직접 찾아 클릭합니다.
          5. 
          
        5. 실행 추적디버거처럼 실행 중인 줄과 변수 값의 변화를 단계별로 봅니다.
          6. 
          
        6. 직접 수정코드의 값을 고쳐 과제를 해결하고 결과 변화를 확인합니다.
          7. 
          
        7. 언어 비교같은 프로그램을 세 언어로 나란히 놓고 차이를 분석합니다.
          8. 
        
        
      
        
      
        
        
        코드를 구성하는 다섯 가지 토큰
        
        
        컴파일러가 코드를 읽을 때 가장 먼저 하는 일이 토큰 분해입니다. 토큰을 눌러 의미를 확인해 보세요.
        
        
        
        
        
        
        
        
        
          키워드·내장 함수식별자(변수 이름)문자열숫자연산자·기호
        
        
        
        수업 운영 팁 — 2단계(바이브 코딩)로 결과물을 먼저 보여 동기를 만든 뒤, 3단계 해설을 함께 소리 내어 읽고, 6단계 과제를 개인 실습으로 주면 효과적입니다. 진도 기록은 이 브라우저에만 저장됩니다.
